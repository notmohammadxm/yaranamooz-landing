# یاران‌آموز — وب‌سایت معرفی محصول

این مخزن شامل وب‌سایت عمومی معرفی **یاران‌آموز** است؛ یک سامانهٔ یکپارچه برای مدیریت فرایندهای آموزشی، پرورشی و تربیتی مدرسه.

- وب‌سایت: [yaranamooz.ir](https://yaranamooz.ir)
- ورود به سامانه: [app.yaranamooz.ir](https://app.yaranamooz.ir)
- مخزن سامانه: [notmohammadxm/yaranamooz](https://github.com/notmohammadxm/yaranamooz)

## معرفی

لندینگ‌پیج با هدف معرفی قابلیت‌های محصول به مدیران مدارس، معاونان، مربیان، معلمان راهنما و کاربران آموزشی طراحی شده است. محتوا و ساختار صفحه، قابلیت‌های پیاده‌سازی‌شده در سامانه را معرفی می‌کند و آمار یا شاخص عملکرد ساختگی به‌عنوان دادهٔ واقعی محصول نمایش نمی‌دهد.

## بخش‌های وب‌سایت

- **Hero و معرفی محصول:** پیام اصلی، مسیر ورود به سامانه و پیش‌نمایش مفهومی داشبورد.
- **امکانات اصلی:** ساختار آموزشی و آزمون، پیشرفت و رتبه‌بندی، دنا، پیام‌رسان، کتابخانهٔ محتوا، تقویم، گزارش‌ها، نقش‌ها و دستیار هوش مصنوعی.
- **سامانهٔ دنا:** معرفی امتیازدهی، سطوح لیگ فتح/جهاد/مقاومت، فصل‌ها، حساب دانش‌آموز، اردوها و گردش کار Excel.
- **دستیار هوش مصنوعی:** معرفی اتصال به GLM، DeepSeek یا سرویس سفارشی سازگار و تحلیل داده‌های مجاز سامانه.
- **ماژول‌های مکمل:** پیام‌رسان، انتشار محتوا، تقویم و خروجی‌های مدیریتی.
- **نقش‌ها و دسترسی‌ها:** توضیح کنترل دسترسی ماژول‌ها و محدوده‌های پایه/کلاس.
- **فرایند شروع:** نصب، تعریف کاربران، ساختاردهی و پیگیری گزارش‌ها.
- **امنیت و حریم داده:** معرفی کنترل‌های امنیتی و محدودیت‌های داده در دستیار هوش مصنوعی.
- **FAQ و CTA:** پاسخ به پرسش‌های متداول و پیوند ورود به سامانه.

## ساختار مخزن

~~~text
yaranamooz-landing/
├── assets/
│   ├── favicon.svg        # آیکون اختصاصی سایت
│   ├── og-cover.svg       # تصویر برداری اشتراک‌گذاری
│   └── font/
│       └── Yaran.woff2    # فونت اختصاصی پروژه
├── index.html             # صفحهٔ اصلی؛ HTML/CSS/JavaScript مستقل
└── README.md
~~~

## فناوری‌ها

- HTML5 معنایی و راست‌چین (`lang="fa"` و `dir="rtl"`).
- CSS3 با طراحی اختصاصی، متغیرهای طراحی، Grid، Flexbox و media query.
- JavaScript خالص (Vanilla) بدون وابستگی به فریم‌ورک یا CDN.
- Intersection Observer برای نمایش تدریجی بخش‌ها و تشخیص بخش فعال منو.
- انیمیشن‌های CSS برای پیش‌نمایش داشبورد، نمودارها، عناصر تزئینی و کارت‌ها.
- تگ‌های Open Graph، Twitter Card و دادهٔ ساختاریافتهٔ SoftwareApplication.

## طراحی واکنش‌گرا و دسترس‌پذیری

صفحه برای نمایشگرهای دسکتاپ، تبلت و موبایل بازچینی می‌شود. منوی موبایل با دکمه، لینک‌های داخلی و کلید Escape باز و بسته می‌شود. از عناصر معنایی، برچسب‌های دسترس‌پذیری، وضعیت باز/بستهٔ منو، نشانگر `:focus-visible` و ویژگی `prefers-reduced-motion` استفاده شده است.

## اجرا و توسعه

این پروژه به فرایند build، نصب پکیج یا سرور برنامه‌نویسی نیاز ندارد. کافی است مخزن را دریافت و `index.html` را در مرورگر باز کنید یا پوشه را روی یک میزبانی استاتیک (مانند GitHub Pages یا وب‌سرور معمولی) منتشر کنید.

~~~bash
git clone https://github.com/notmohammadxm/yaranamooz-landing.git
cd yaranamooz-landing
~~~

فونت اختصاصی از مسیر `assets/font/Yaran.woff2` بارگذاری می‌شود. آیکون سایت و تصویر اشتراک‌گذاری نیز فایل‌های SVG داخل `assets/` هستند؛ بنابراین صفحه برای نمایش اصلی به کتابخانه، فونت یا تصویر خارجی وابسته نیست.

## یادداشت دقت محتوا

پیش‌نمایش داشبورد داخل Hero یک تصویر مفهومی با داده‌های نمونه است و گزارش واقعی یا آمار عملکرد مدرسه محسوب نمی‌شود. قابلیت نصب PWA به معنی آفلاین‌بودن کامل سامانه نیست؛ صفحات، APIها و عملیات اصلی به اتصال شبکه نیاز دارند. فعال‌سازی دستیار هوش مصنوعی نیز به پیکربندی سرویس و کلید API توسط مدیر نیاز دارد.
